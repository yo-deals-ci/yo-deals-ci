# Yo Deals CI — Site vitrine

Site vitrine développé pour Yo Deals CI, activité d'import-revente en ligne basée à Abidjan, Côte d'Ivoire.

## Aperçu

Site en ligne : https://yodealsci.netlify.app

## Fonctionnalités

- Catalogue produits filtrable par catégorie (Électronique, Maison, Véhicules)
- Fiches produits avec photos, prix et disponibilité
- Prise de commande directe via WhatsApp (lien pré-rempli)
- Section de présentation de l'activité et du fondateur
- Design responsive (mobile, tablette, desktop)

## Technologies utilisées

- HTML5
- CSS3 (Flexbox, CSS Grid, animations)
- JavaScript (vanilla) pour le filtrage du catalogue et le menu mobile

## Structure

Le site est un fichier unique (`index.html`) avec HTML, CSS et JavaScript intégrés, incluant les images des produits encodées en base64 pour un déploiement simple sans dépendances externes.
